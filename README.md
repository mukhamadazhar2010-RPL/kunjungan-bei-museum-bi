# Kunjungan BEI dan Museum Bank Indonesia

Deskripsi

Proyek website sederhana yang mendokumentasikan kegiatan kunjungan edukatif ke Bursa Efek Indonesia (BEI) dan Museum Bank Indonesia (MUBI).

Tujuan

- Mendokumentasikan pengalaman kunjungan.
- Mengenal pasar modal Indonesia.
- Mempelajari sejarah Bank Indonesia.

Teknologi

- HTML5
- CSS3

Fitur

- Informasi kunjungan BEI.
- Informasi kunjungan Museum Bank Indonesia.
- Dokumentasi foto.
- Kesimpulan pengalaman kunjungan.

Cara Menjalankan

1. Unduh atau clone repository.
2. Buka file "index.html" menggunakan browser.
3. Pastikan file CSS dan folder gambar berada pada lokasi yang sesuai.
